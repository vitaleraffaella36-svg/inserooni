INTELLIGENZA SOVRUMANA INDIZI — VICO EQUENSE

Contenuto cartella:
- index.html : interfaccia principale
- style.css : grafica nera/arancione
- app.js : logica di ricerca locale
- data.js : base dati ricavata dal master Vico_Equense_Knowledge_Base_v5.4_Unificata.xlsx
- logo_drago.png : logo stilizzato del drago che sputa fuoco

Uso:
1. decomprimere lo ZIP
2. aprire index.html con Chrome, Edge o Firefox
3. inserire uno o più indizi nella barra di ricerca

Note:
- il motore non usa API esterne
- le ricerche avvengono direttamente nel browser
- il dataset parte dal master unificato v5.4
- le strutture ricettive provengono dal registro 2026 consolidato nel master
